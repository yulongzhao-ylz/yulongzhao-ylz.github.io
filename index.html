Statistical methods for process data.

My research focuses on process data: the time-stamped action logs people leave as they work through interactive tasks. I build interpretable and deployable models for these data: which actions matter and when, how to flag users at risk in real time without too many false alarms, and what hidden traits and states drive behavior. I also work on time-series forecasting and regime-shift detection for scientific data. Advised by Prof. Xueying Tang.

Can we tell that a user is heading toward failure while they are still working, and step in early without bothering the users who would have succeeded anyway?

The demo replays three users in the same ticket-machine task. At each step a sequence model scores the risk of failing, and an alert fires only after two high-risk steps within any four, a rule calibrated so that false alarms stay under 5%.

Predictive Modeling of Sequential User Behavior

Interpretable prediction · time-varying effects · NSF #2310664

Captures both which actions users take and when they take them.

Details

Built an interpretable predictive model for timestamped user-event sequences that captures both which actions users take and when they take them, including time-varying behavioral effects missed by count-based features. Improved 10-fold cross-validated accuracy from 93.5% to 96.1% and cut log loss by 50% (0.237 to 0.118) on 19,089 events from 2,668 users, outperforming the count-feature baseline on every fold. Identified timing-sensitive behavioral signals whose predictive effect reverses across the task, revealing information fundamentally lost by conventional aggregate features. See the interactive curve at the top.

Unsupervised Skill and State Discovery from User Sequences

Structured latent-variable models · hidden Markov models · sparse skill maps

Learns stable skills and evolving states, and which skill drives which behavior, with no labels.

Details

Designed a structured latent-variable model that jointly learns stable user skills and evolving behavioral states from multistep interaction sequences. Developed sparse skill-to-behavior mappings that learn which latent skills drive actions, interface choices, and state transitions, instead of requiring those relationships to be specified a priori. Applied the framework to 1,340 users in a multi-interface problem-solving task, recovering interpretable skills, behavioral states, and skill–action relationships without manual state labeling.

Real-Time Early Warning with a Controlled False-Alarm Rate

Online risk scoring · sequence models · threshold calibration

Flags users heading toward failure while they are still working, without crying wolf.

Details

Built an online early-warning framework that continuously updates failure risk from partial user-action sequences, enabling intervention before task completion. Designed and calibrated decision thresholds to maximize early detection while explicitly controlling the false-alarm rate at ≤5%. Benchmarked GRU, temporal CNN, Transformer, and leakage-safe logistic baselines; the best temporal CNN detected 98.9% of failing users at precision ≥0.98 while keeping false alarms below 4% across all three tasks, compared with 85.6% detection for GRU.

Multivariate Time-Series Forecasting & Regime-Shift Detection

Walk-forward forecasting · recurrence-based detection · IMSI cluster, NSF #1929348

Forecasts biological change from environmental records and tests where regimes shift.

Details

Built a leakage-free walk-forward forecasting pipeline using PCA and RBF-SVR, reducing MSE by 38% versus the historical-mean baseline and outperforming it in all 18 evaluation settings. Developed a multivariate regime-shift detection pipeline using recurrence-based features and multiple-testing correction, identifying statistically significant environmental shifts and separating robust signals from preprocessing-sensitive findings.
